# Lessons

## multica-api-echoes-description

- **cue**: `multica: decode response: unexpected end of JSON input` right after a POST /api/issues that actually created the issue
- **lesson**: Read the full response body from the Multica issues API — it echoes the whole description back, so any small fixed read cap truncates the JSON and fakes a failure.
- **evidence**: Real run logged `ERROR multica cable: could not file client request error="multica: decode response: unexpected end of JSON input"` while the issue (NRA-5555) was created; a `io.LimitReader(resp.Body, 1024)` cut the ~1.1 KB response. Raised to 64 KB and a regression test with a 4 KB body passes.
- **confidence**: high

## odooclaw-config-path-env

- **cue**: gateway fails with `model "" not found in model_list` although config.json sits in `$ODOOCLAW_HOME`
- **lesson**: Point the gateway at its config with `ODOOCLAW_CONFIG=<path>`; `ODOOCLAW_HOME` only relocates the workspace, never the config file.
- **evidence**: `GetConfigPath()` in `cmd/odooclaw/internal/helpers.go` reads `ODOOCLAW_CONFIG` else `~/.odooclaw/config.json`; a config placed at `$ODOOCLAW_HOME/config.json` was silently ignored until `ODOOCLAW_CONFIG` was set.
- **confidence**: high
